| 列 | 何を書くか |
| --- | --- |
| 行 | 振り分け表の行き先の表の項目（`<Issue 番号>-<連番>`）か、要求の受け入れ条件の持ち主の表の行（`要求 <行番号>`） |

| 元の行き先 | 振り分け表の行き先の子の列（コミット `e41a836de`）。持ち主の先頭だけを書く |

| 理由 | 行き先を選んだ理由を 1 句。`作らない` の行は作らない理由 |
