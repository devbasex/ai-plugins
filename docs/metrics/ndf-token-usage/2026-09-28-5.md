## 作り方

```bash
python3 scripts/token-usage-snapshot.py --released 10.17.41 --until 2026-09-28T12:55:00Z --min-version 10.17.37
python3 scripts/token-usage.py --min-version 10.17.37 --until 2026-09-28T12:55:00Z --by version   # 末尾の「集計の出力」
```
