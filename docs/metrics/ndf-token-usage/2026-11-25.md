# ndf の版ごとのトークン消費と所要時間（2026-11-25 集計・11.0.36 のリリース）

**11.0.36 を正式版として出したときの記録である。** 打ち切りの時刻は `2026-11-25T00:11:00Z`。表の最初の行は 11.0.33（前の記録: 2026-11-24-9.md）。既定では前の記録の最後の版で、記録どうしが 1 行ずつ重なる。生の記録・会話の本文・リポジトリ名・会話の ID は残していない。集計した日時点の記録で、以後の記録の増減には追随しない。

## 作り方

同じ打ち切りの時刻で走らせ直すと、記録が残っている間は同じ `.json` ができる。ただし kiro の記録はターンに時刻を持たないため、打ち切りをまたいで進行中だった席は credit が変わりうる。

```bash
python3 scripts/token-usage-snapshot.py --released 11.0.36 --until 2026-11-25T00:11:00Z --min-version 11.0.33
python3 scripts/token-usage.py --min-version 11.0.33 --until 2026-11-25T00:11:00Z --by version   # 末尾の「集計の出力」
```
