# ndf の版ごとのトークン消費と所要時間（2026-09-23 集計）

**10.14.0〜10.17.x の基準である。** 会話の記録は 90 日で消える（`cleanupPeriodDays: 90`、
集計時点の最古は 2026-06-13）ため、消える前に集計値だけを残した（#893）。生の記録・会話の本文・
リポジトリ名・会話の ID は残していない。**集計した日時点の記録で、以後の記録の増減には追随しない。**

## 作り方

```bash
python3 scripts/token-usage.py --min-version 10.14.0 --by version                 # この文書の表
python3 scripts/token-usage.py --min-version 10.14.0 \
  --by version,mode,model,cc,reviewers --format json                              # 2026-09-23.json
```

- 対象は `~/.claude/projects/` の全プロジェクトのうち、ndf の Skill を起動した会話。版は記録中の
  `ai-plugins/ndf/<版>/skills/` の最初の出現で決める
- 外部 CLI は codex（`~/.codex/sessions`）と kiro（`~/.kiro/sessions/cli`）と cross-review の
  claude の席。**kiro はトークン数を記録しない**（380 ターンすべて 0）ため credit だけを載せる。
  **agy は読んでいない**（会話ごとの SQLite で、形式を確かめていない）
- 数え方の前提（PR の数え方・所要時間の打ち切り・外部 CLI の寄せ方）は
  [issues/issue-893-token-usage-requirements.md](../../../issues/issue-893-token-usage-requirements.md) にある

## 比べるときの注意

- **合計では比べない。** 会話ごとに作業の大きさが違うため、表は「PR 1 本あたり」「1 起動あたり」に
  そろえてある
- **モデルと Claude Code の版が版ごとに違う。** 軸を分けた値は同じ日付の `.json` にある
  （`by` が `version,mode,model,cc,reviewers`）。10.14.0 は claude-opus-5 だけ、10.15.1 は
  claude-opus-5 / claude-opus-5-5 / claude-fable-5-1 が混ざり、10.16.0 以降は claude-opus-5-5 だけである
- **10.14.0 の持ち場の多くは `その他` である。** 持ち場の語彙（#768）より前の記録で、
  サブエージェントの `description` の先頭語が語彙に無い
- **件数が少ない版がある。** 10.17.0 は PR を作った会話が 1 件である。10.16.1 と 10.17.1 は
  表に出ない（その版で始めた会話が集計の時点で無く、会話の版は最初に読んだ版で決まる）
- **PR 1 本あたりの `所要` は conductor の所要である。** 行の間隔を 30 分で打ち切って足した値を
  PR の数で割っている
