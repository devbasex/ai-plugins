## 作り方

同じ打ち切りの時刻で走らせ直すと、記録が残っている間は同じ `.json` ができる。ただし kiro の記録はターンに時刻を持たないため、打ち切りをまたいで進行中だった席は credit が変わりうる。

```bash
python3 scripts/token-usage-snapshot.py --released 10.26.1 --until 2026-10-30T21:36:00Z --min-version 10.25.0
python3 scripts/token-usage.py --min-version 10.25.0 --until 2026-10-30T21:36:00Z --by version   # 末尾の「集計の出力」
```
