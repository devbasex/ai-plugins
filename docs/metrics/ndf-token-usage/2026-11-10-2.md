## 作り方

```bash
python3 scripts/token-usage-snapshot.py --released 10.27.52 --until 2026-11-10T23:06:00Z --min-version 10.27.50
python3 scripts/token-usage.py --min-version 10.27.50 --until 2026-11-10T23:06:00Z --by version   # 末尾の「集計の出力」
```
