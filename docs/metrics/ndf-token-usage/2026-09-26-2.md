**10.17.28 を正式版として出したときの記録である。** 打ち切りの時刻は `2026-09-26T04:08:00Z`。表の最初の行は 10.17.26（前の記録: 2026-09-26.md）。既定では前の記録の最後の版で、記録どうしが 1 行ずつ重なる。生の記録・会話の本文・リポジトリ名・会話の ID は残していない。集計した日時点の記録で、以後の記録の増減には追随しない。

## 作り方

同じ打ち切りの時刻で走らせ直すと、記録が残っている間は同じ `.json` ができる。ただし kiro の記録はターンに時刻を持たないため、打ち切りをまたいで進行中だった席は credit が変わりうる。

```bash
python3 scripts/token-usage-snapshot.py --released 10.17.28 --until 2026-09-26T04:08:00Z --min-version 10.17.26
python3 scripts/token-usage.py --min-version 10.17.26 --until 2026-09-26T04:08:00Z --by version   # 末尾の「集計の出力」
```
