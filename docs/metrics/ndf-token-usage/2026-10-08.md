## 作り方

```bash
python3 scripts/token-usage-snapshot.py --released 10.17.67 --until 2026-10-08T06:58:00Z --min-version 10.17.65
python3 scripts/token-usage.py --min-version 10.17.65 --until 2026-10-08T06:58:00Z --by version   # 末尾の「集計の出力」
```
