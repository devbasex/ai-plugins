## 作り方

```bash
python3 scripts/token-usage-snapshot.py --released 10.17.51 --until 2026-10-01T12:51:00Z --min-version 10.17.49
python3 scripts/token-usage.py --min-version 10.17.49 --until 2026-10-01T12:51:00Z --by version   # 末尾の「集計の出力」
```
