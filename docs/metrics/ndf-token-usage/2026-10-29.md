# ndf の版ごとのトークン消費と所要時間（2026-10-29 集計・10.24.0 の配布）

**10.24.0 を正式版として出したときの記録である。** 打ち切りの時刻は `2026-10-29T22:15:00Z`。表の最初の行は 10.22.0（前の記録: 2026-10-28.md）。既定では前の記録の最後の版で、記録どうしが 1 行ずつ重なる。生の記録・会話の本文・リポジトリ名・会話の ID は残していない。集計した日時点の記録で、以後の記録の増減には追随しない。

## 作り方

同じ打ち切りの時刻で走らせ直すと、記録が残っている間は同じ `.json` ができる。ただし kiro の記録はターンに時刻を持たないため、打ち切りをまたいで進行中だった席は credit が変わりうる。

```bash
python3 scripts/token-usage-snapshot.py --released 10.24.0 --until 2026-10-29T22:15:00Z --min-version 10.22.0
python3 scripts/token-usage.py --min-version 10.22.0 --until 2026-10-29T22:15:00Z --by version   # 末尾の「集計の出力」
```

## 比べるときの注意

- **PR を作った会話が 2 件以下の版:** 無し。作業の中身の違いが版の違いより大きい
- **CHANGELOG.md にあって表に出ない版:** 10.23.0, 10.24.0。その版で始めた PR つきの会話が無い（会話の版は最初に読んだ版で決まる）
- **打ち切りの 30 分前以降にも行がある会話を含む版:** 無し。進行中だった会話は、値が打ち切りの時刻までの分である
