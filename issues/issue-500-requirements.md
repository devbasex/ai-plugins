# #500: 既存の README.md 22 本を、#498 で決めた規約へ合わせる

設計は [issue-500-design.md](issue-500-design.md) にある。この文書は「何を満たすか」だけを扱う。

## 依頼（原文）

> **#498 で決めた規約へ、既存の `README.md` を合わせる。** #498 は規約を定める課題で、既存の
> 書き直しを「やらないこと」に置いた。**適用の側に番号が無いと、規約だけができて既存が
> 放置される。**
>
> **全部を同じ扱いにしない。** #498 が定める役割（入口 / 索引 / 規約）で分かれる。
>
> **移すのではなく、正本を決めて残りを消す形になる箇所がある。**
>
> **版数の検査が記載を見つけられなくなる。** （中略）移すなら検査の読む先も一緒に動かす。
>
> **リンクが切れる。**

（issue #500 の本文から抜粋。完了条件 6 件と「やらないこと」2 件は本文にある）

## 解釈

**`README.md` の名前を持つ 22 本を、規約 `plugins/ndf/skills/markdown-writing/03-readme-roles.md` の
役割へ当てはめる。** 役割に合わない節だけを動かし、合っている節には触らない。

- 規約の役割を持つ文書は、`README.md` 以外の名前にする
- 入口の役割を持つ文書からは、その文書を開く読み手と違う読み手へ向けた規約・手順を外す
- 2 つの文書に同じ主題があれば、正本を決め、残りを正本へのリンクにする

## 目的

- 根の `README.md` を開いた利用者が、何ができるかと入れ方へ、開発の規約を通らずに届く
- 同じ手順が 2 か所にあって片方だけが古くなる状態を、`README.md` から無くす
- 規約を探しに来た人が、名前から規約の文書を見つけられる

## 前提

- 前提 1: 22 本は `origin/develop`（`55d94f9`、2026-09-13）の `git ls-files -z '*README.md'` の
  結果である（計 3228 行）。issue 起票時の 3211 行から 17 行増えた
- 前提 2: 版数の扱いの正本 `docs/versioning-and-distribution.md` は #499 で作られた。この課題は
  この文書を書き換えない。#566 の設計 PR #604 が章 2 の位置を決める語を固定するため、重ねない
- 前提 3: 検査 `check-doc-staleness.py` は根の `README.md` から、概要の版数と Skill 数、一覧表の
  版数を読む。これらは「概要」と「利用可能なプラグイン」にあり、どちらも入口の記載として残る
- 前提 4: 記録（`issues/`、`docs/development-history/`、`docs/presentations/`）にある旧いパスと
  節名は書き換えない。起きたことをそのまま残す文書であり、リンク検査の走査にも入らない

## 対象範囲

含む:

- 22 本すべての役割の判定と、その記録
- 役割に合わない節を持つ文書の手入れ（どれが該当するかは設計が判定する）
- 手入れで動いた節・ファイルを指す参照の追随（リンク、節名での言及、スクリプトの案内文、テストの雛形）

含まない:

| 扱わないもの | 理由 |
| --- | --- |
| 規約そのものを決めること | #498 が持つ |
| 正本 `docs/versioning-and-distribution.md` の書き換え | #566 と重なる |
| `README.md` 以外の文書どうしの重なり | 規約の適用の対象外。例は `CONTRIBUTING.md` と開発ガイドの検証コマンド |
| 残す節の中にある古い値の修正 | 見つけたものは範囲外の課題として起票する |
| クラス図・データ構造・非機能の設計 | 型も永続データも持たない文書の変更で、非機能の条件も無い |
| 記述を消すこと | 移すのであって減らすのではない。重複を解消する箇所だけが例外で、どちらを正本にしたかを設計文書に残す |

## 用語

| 用語 | 意味 |
| --- | --- |
| 規約 | `plugins/ndf/skills/markdown-writing/03-readme-roles.md` |
| 役割 | 規約が定める入口 / 索引 / 規約の 3 つ。生成物の素にあたる雛形はこの 3 つの外に置く |
| 正本 | 同じ主題を持つ文書のうち、残す側 |
| 手入れ | 節を移す、正本へのリンクへ置き換える、ファイルの名前を変える、のいずれか |

## 影響

| 対象 | 影響 |
| --- | --- |
| 配布物 | `plugins/` 配下の説明文書の名前と本文が変わる。Skill・hook・マニフェストは変わらない |
| 検査 | 読む先は変わらない。案内文に書かれた規約のパスが変わる |
| 利用者の手順 | 変わらない。手順の置き場所がリンク先へ移る |

## 境界

| 区分 | 内容 |
| --- | --- |
