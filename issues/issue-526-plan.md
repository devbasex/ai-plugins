# #526: 設計文書で、表から導ける値を数え直す（実装計画）

## 関連リンク

- issue: https://github.com/devbasex/ai-plugins/issues/526
- 要求と受け入れ条件: [issue-526-requirements.md](issue-526-requirements.md)
- 設計: [issue-526-design.md](issue-526-design.md)（設計 PR #574 でマージ済み）

## モード

`standard`。配布する Skill（`design`）の手順を変え、利用者のエージェントの振る舞いが変わる。

## 目的と非目的

達成したい状態:

- 設計文書の本文に書いた導ける値が、表を数え直した値で照らされる（F1・F2）
- 値の集合へ値を足す設計で、既存の規則が構成要素の表へ載る（F3）

やらないこと:

- 7 つ目の対を足すこと（#493）。対の数は 6 のまま
- 検査スクリプトを足すこと（設計の決定 4）
- 既存の設計文書を数え直すこと

## 受け入れ条件

要求文書の 9 件をそのまま使う。番号は要求文書の並びである。

## 修正対象

- `plugins/ndf/skills/design/references/design-template.md`
- `plugins/ndf/skills/design/SKILL.md`
- 生成物（`bash scripts/build-runtime-plugins.sh` が同期する先）

## タスク分解

**本文は設計文書の「変更後の本文」をそのまま置く。** 表現を変えない。

### Task 1: 3 つ目の対を広げ、表を直したときの段落を足す

- **対象ファイル:** `design/references/design-template.md`
- **変更内容:** 対の表の 3 行目を「導ける値の記述 ↔ その値を導いた表」へ差し替える。
  「確かめた結果は残さない。」の段落の直後へ 2 段落を足す
- **満たす受け入れ条件:** 1・2・3・4・5
- **進め方:** 振る舞いを持つコードが無く、テスト駆動は適用しない（設計の「テスト設計」）。
  変更の前に下の「確かめ方」を実行し、条件 1〜4 が満たされていない（落ちる）ことを先に見る

### Task 2: 手順 2 に値の集合へ値を足す設計の段落を足す

- **対象ファイル:** `design/SKILL.md`
- **変更内容:** 「タスクを機械的に導けるだけの情報を書く。」の段落の直後へ段落を足す
- **満たす受け入れ条件:** 6・7・8
- **進め方:** Task 1 と同じ。変更の前に条件 6・7 が落ちることを先に見る

### Task 3: 生成物を同期し、検査を通す

- **対象:** 配布物の同期先
- **満たす受け入れ条件:** 9
- **進め方:** 下の検査を実行し、終了コードを PR へ残す

## 確かめ方

受け入れ条件ごとに、変更の前に落ち、変更の後に通ることを見る。`T` は
`plugins/ndf/skills/design/references/design-template.md`、`S` は
`plugins/ndf/skills/design/SKILL.md` を指す。

| 条件 | 式（通る条件） |
| --- | --- |
| 1 | `grep -c '^| 導ける値の記述 ↔ その値を導いた表 |' T` が 1 |
| 2 | 同じ行に `行やセルの数`・`最大と最小`・`「すべて」` の 3 語がそろう |
| 3 | 同じ行に `直下の表に限らない`、段落に `分割した別のファイルにあっても対象にする` がある |
| 4 | `grep -c '表を直したときは、その表から導いた記述を数え直す' T` が 1 |
| 5 | 対の節の表の行数（見出し行と区切り行を除く）が 6 で、`T` の冒頭と `S` の手順 4 がどちらも「6 つ」と書く |
| 6 | `S` の「### 2.」から「### 3.」の間に `値の集合へ値を足す設計では` がある |
| 7 | 同じ範囲に `集合の名前と既存の値の名前で配布物を検索する` と `新しい値が通る手順を読む` の 2 行の箇条書きがある |
| 8 | `T` の対の節と `S` の手順 4 に `値の集合` が 0 件 |
| 9 | 下の検査がすべて終了コード 0 |

**PR #516 の 2 件を新しい対で拾えるかは、読み合わせで確かめる。**

| PR #516 の指摘 | 新しい 3 つ目の対のどの語に当たるか |
| --- | --- |
| 「必須の工程が最も多い」（列ごとの `R` の数の比較。表は別の節） | 「最大と最小」と「直下の表に限らない」 |
| 「9 セル」（セルの数の内訳の合計） | 「行やセルの数」 |
