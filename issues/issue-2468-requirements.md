## 何が起きたか

2026-11-03〜04、cross-review（複数の AI がレビューし、指摘が無くなるまで直しを繰り返す機能）が、役に立たないラウンドを繰り返した。利用者の指摘は「なんか役に立たないことやってない？」である。

- Pull Request https://github.com/devbasex/ai-plugins/pull/2452 は、再開のたびにラウンドを数え直して通算 12 ラウンドになった（上限 4 × 再開 3 回）。費用は claude 約 $4.9、codex の入力約 1,700 万 token
- 見送った同じ重い指摘（major）が、ラウンドごとに出直した（同じ指摘が 10〜12 ラウンドで 3 回。後に https://github.com/devbasex/ai-plugins/issues/2466 へ起票した）
- 12 ラウンド目は指摘 0 件なのに上限で終わり（片方の AI の判定が「変更を要求」だった）、自動で流していた作業の計画（プラン）が止まった
- Pull Request https://github.com/devbasex/ai-plugins/pull/2463 は 1 ラウンド目が指摘 0 件だったのに、テストの直しなどを見せるために 2〜4 ラウンドを足した

同じ事象は、2026-11-10 と 11-17 にも別の Pull Request で確認した（この Issue のコメント）。

## 種類

機能追加（再開をまたいだ上限、費用・時間の上限、見送った指摘の起票、流し直しの回数の制限は、今の手順書に約束が無い）

## 今の姿

2026-11-27 に `origin/main`（ndf 11.0.45）のコードと手順書を読んで確かめた。同じコミットで cross-review のテスト 660 件が通る。

| 受け入れ条件 | 今 |
| --- | --- |
| 1. 見送りの出直し | 理由を添えて見送った指摘は、出直しても扱わない。ただし同じ指摘かは本文の先頭部分の一致で決めるので、言い回しが変わると新しい指摘になる。起票する処理は無い |
| 2. 指摘 0 件 | 満たしている。レビューする AI は指摘の一覧だけを返し、扱う指摘が無ければ収束になる。読めない相手がいたラウンドは収束にしない |
| 3. 再開での数え直し | 打ち直すたびに、前の続きから上限の数だけ回す。手順書もそう定めている |
| 4. 費用・秒・ラウンドの上限 | `.ndf/review.json` にこの上限の設定は無い。ラウンドの上限はコマンドの `--max-rounds`（既定 3）だけである |
| 5. 同じステップの流し直し | `ndf plan queue --resume` は完了したプランを飛ばして流し直す。同じステップで止まった回数を数える処理は、コードに見当たらない（実行では確かめていない） |

## 何を足すか・変えるか

| | 今 | 足した後 |
| --- | --- | --- |
| 見送った指摘の出直し | 扱わない | 扱わず、残した先（Issue か Pull Request の記録のコメント）の URL が報告に載る |
| ラウンドの上限 | 起動 1 回ごと | 収束していない再開をまたいだ合計（収束した後は数え直す） |
| 費用・秒・ラウンドの上限 | 設定が無い | `.ndf/review.json` に置き、当たれば止まる |
| 同じステップで 2 回止まったプラン | `--resume` で何度でも流せる | 流さず、案内を返して止まる |

## なぜ困るか

役に立たないラウンドと流し直しに、時間と AI の利用料を使い続ける。上限が数値で設定に無いので、どこでやめるかが実行する側の判断に任される。

## 目的

役に立たない繰り返しを止め、cross-review の費用と時間に上限がある状態にする。

## 対象範囲

含む:
- 見送った指摘が出直したときの扱い
- 指摘 0 件のラウンドの判定
- 再開をまたいだラウンドの数え方
- `.ndf/review.json` の費用・秒・ラウンドの上限
- 同じステップで繰り返し止まるプランの流し直し

含まない:
- プロジェクトの判断基準（`.ndf/mvv.md`）の文の変更
- 収束した後に足したコミットがテストや CI の直しだけのときに、ラウンドを足さない仕組み（起票の「直すこと」の 3。受け入れ条件が無い）
- 2 ラウンド目以降の範囲と、実装の Pull Request の上限の既定（ https://github.com/devbasex/ai-plugins/issues/3780 が持つ）
- 重要度を下げる条件（ https://github.com/devbasex/ai-plugins/issues/4363 が持つ）

## 受け入れ条件

- [ ] 1. 見送った指摘が出直しても、ラウンドが増えない。MVV の Value 6 に当たる指摘は起票した Issue の URL が、ほかは Pull Request の記録のコメントの URL が報告に載る
- [ ] 2. 指摘 0 件のラウンドで `final` が `converged` になり、プランが止まらない
- [ ] 3. 収束していない再開をまたいでも、ラウンドの合計が `--max-rounds` を越えない。収束した後に差分を足した Pull Request は数え直す
- [ ] 4. `.ndf/review.json` の上限（費用・秒・ラウンド）のどれかに当たると cross-review が止まり、残りの指摘を条件 1 と同じ分け方で残し、その URL が報告に載る
- [ ] 5. 同じステップが 2 回止まったプランを `--resume` すると、流さずに終了コードと案内で止まる
- [ ] 6. `.ndf/review.json` に上限を書かないプロジェクトでも、今の `version: 1` の設定はそのまま読める（テスト）
