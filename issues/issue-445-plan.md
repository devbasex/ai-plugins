# #445: リンク検査に見出しへの参照の照合を足す（実装計画）

## 関連リンク

- 要求と受け入れ条件: [issue-445-requirements.md](issue-445-requirements.md)
- 設計: [issue-445-design.md](issue-445-design.md)

## モード

standard（1 本の検査スクリプトへ照合を足し、テストを新設する。設計 PR #501 はマージ済み）

## 目的と非目的

達成したい状態:

- `#見出し` と `other.md#見出し` の参照が存在しない見出しを指すとき、検査が終了コード 1 で落ちる

やらないこと:

- 走査する文書の母集合を広げること（#543 が扱う）
- 既存の除外（フェンス・引用行・`should_skip`）を変えること

## 受け入れ条件

要求文書の 9 件をそのまま使う。番号は要求文書の並び順である。

## 修正対象

- `scripts/check-markdown-links.py`（変更）
- `scripts/tests/test_check_markdown_links.py`（新設）

## タスク分解

### Task 1: 同じ文書の見出しを照合する

- **変更内容:** `slugify` / `heading_anchors` / `anchor_refs` と名前の控えを足し、`#名前` を照合する。
  フェンスと引用行の除外は既存の走査を関数へ切り出して見出しの抽出と共有する
- **満たす受け入れ条件:** 1・3・4・5・7
- **進め方:** 失敗するテスト → 通す最小実装 → 整理

### Task 2: 別の文書の見出しを照合する

- **変更内容:** `相手.md#名前` を `should_skip` に通し、相手が在り、検査の対象である場合だけ照合する
- **満たす受け入れ条件:** 2・8
- **進め方:** 失敗するテスト → 通す最小実装 → 整理

### Task 3: リポジトリ全体で落ちないことを確かめる

- **変更内容:** コードは足さない。`python3 scripts/check-markdown-links.py --root .` の終了コード 0 と、
  壊れた参照を 1 つ入れると落ちることを証跡として取る
- **満たす受け入れ条件:** 6・9

## リスクと対処

| リスク | 対処 |
| --- | --- |
| 既存の文書に解決できない参照が見つかる | 設計の実測では 0 件。見つかれば設計の対象範囲に照らし、範囲外なら `out-of-scope` で起票する |
| 触る対象の構造（`main` に走査が直書き） | 範囲が 1 ファイルでテストを同時に足すため、実装の後の構造改善で足りる |

## 切り戻し手順

- スクリプト 1 本とテスト 1 本の変更で、データ移行を含まない。コミットを戻せば元の検査に戻る

- [ ] `uv run --with pytest pytest scripts/tests -q` が通る
