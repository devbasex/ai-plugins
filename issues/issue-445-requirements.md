# #445 リンク検査に見出しへの参照の照合を足す

## 目的

`scripts/check-markdown-links.py` は `#見出し` の形の参照を検査していない。そのため、
**その文書に存在しない見出しを指していても終了コード 0 で通る**。節を移した後にリンクが
指す先を失っても、機械が知らせない。

```console
$ sed -n '41,43p' scripts/check-markdown-links.py
def should_skip(target: str) -> bool:
    if not target or target.startswith("#"):
        return True
```

## 決めたこと

### 見出しから参照の名前を作る規則

GitHub の生成規則に合わせる。日本語の見出しをそのまま参照に書く形が、このリポジトリの
文書で使われているためである。

| 段 | 何をするか |
| --- | --- |
| 1 | 見出しの本文から HTML のタグを取り除く |
| 2 | 小文字にする |
| 3 | 文字・数字・結合文字・空白・`-`・`_` 以外を取り除く |
| 4 | 空白を `-` にする |
| 5 | 同じ名前が既にあれば `-1`、`-2` と後ろに付ける |

照合は百分率符号化を解いてから行う。日本語の見出しは符号化された形でも書かれるためである。

### 別の文書への参照も対象にする

`other.md#見出し` の形も照合する。節を移す作業（#500 / #499）で切れるのは、むしろこちらで
ある。実測では 6 件あり、いずれも解決できる。

### 既存の文書に解決できない参照があるか

**この変更の対象となる文書に、解決できない参照は無い**（下記の実測）。#445 が挙げた
`02-apply-and-review.md:332` は #436 の作業で修正済みである。

検査の対象となる文書には、同じ文書の見出しを指す参照が 4 件、別の文書の見出しを指す参照が
6 件ある。この規則で照合すると、10 件すべてが解決できる。

検査を足しても既存の文書は落ちない。落ちるのは、これから壊した場合である。裏付けは
`python3 scripts/check-markdown-links.py --root .` が終了コード 0 で終わることで取る。

## 受け入れ条件

- [ ] 同じ文書に無い見出しを指す `#見出し` の参照があるとき、`check-markdown-links.py` が
      終了コード 1 で落ち、どの文書のどの参照かを出力する
- [ ] 別の文書に無い見出しを指す `other.md#見出し` の参照があるとき、同じく落ちる
- [ ] 見出しが同じ本文で 2 回以上現れる文書で、`-1` を付けた参照が解決できる
- [ ] 日本語の見出しを、そのままの形と百分率符号化した形のどちらで書いても解決できる
- [ ] 現在のリポジトリに対して `python3 scripts/check-markdown-links.py --root .` が
      終了コード 0 で終わる
- [ ] 上の 4 つの振る舞いを検査する自動テストが `scripts/tests/` にあり、
      `uv run --with pytest pytest scripts/tests -q` が通る

## 対象範囲

**含む** — `scripts/check-markdown-links.py` の照合の追加と、その自動テスト。

**含まない**

- 検査する文書の母集合を広げること（`issues/` は現在も対象外で、この変更では変えない）
- 参照が指す先の見出しの文言を直すこと（解決できない参照は現時点で 0 件である）
- コードブロックの中や引用行の中に書かれた参照を対象にすること（現在の除外をそのまま使う）

## 検証手段

| 何を確かめるか | コマンド |
| --- | --- |
| 振る舞い | `uv run --with pytest pytest scripts/tests -q` |
| リポジトリ全体 | `python3 scripts/check-markdown-links.py --root .` |
| 文書の分量 | `python3 scripts/check-doc-line-limit.py` |

## 境界

| 区分 | 中身 |
| --- | --- |
| 常に行う | 既存テストの実行、変更箇所の命名の統一 |
| 確認してから行う | 検査する文書の母集合の変更、既存の除外条件の変更 |
| 行わない | 依頼の範囲外の整理、他の検査スクリプトの変更 |
