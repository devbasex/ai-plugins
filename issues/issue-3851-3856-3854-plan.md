## テストの走らせ方

このリポジトリは CI テストの設定（`.ndf/project.json` の `test.ci.only: true`）を持つ。テストの合否は Pull Request の CI の結果で決め、手元ではテストの suite を走らせない。静的解析（`scripts/check-*.py`・`check-lint.sh`）は手元で走らせる。Pull Request は Task 1 のコミットの push の直後に Draft で出す。

## リスクと対処

| リスク | 対処 |
| --- | --- |
| `context.py` の変更が `script-chain`・`full-test` の判定を変える | `commands`・`loops` を外側の単純コマンドだけのまま残し、退行のテスト（#3851 の条件 9）で縛る。タスクごとにテストを通す |
| 見積の入力の形を変えると、旧い記録が一斉に「見積が無い」になる | 旧い整数の記録は根拠の無い見積として採る（設計の決定 8） |
| 手元でテストを走らせないため、落ちたテストに CI で初めて気づく | 各 push の後に `ndf ci watch` で CI を読み、落ちたら直して push する |
