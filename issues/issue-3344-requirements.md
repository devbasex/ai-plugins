# #3344: #1142 設計レビュー D: DBOS の記録と進行表の置き方（1 つの DB で別のレーンがよそのキューを流す）。C2 の前に決める

正は課題の本文（#3344）で、この文書はその写しである。`spec-copy.py write` で作り直す。手で直さない。

## 目的

ndf-next の耐久の記録（DBOS）と進行表の置き方を、複数のレーンが 1 台で同時に動いても互いのプランを流さず、詰まらず、開発版が出ても途中の実行を失わない形にする。**C2 #3291（プランの実行）の着手の前に決める。** 利用者の決定（2026-11-14 08:3x JST）で、決まるまで lr-flow は C2 に着手しない。

## 対象範囲

- 含む: 決定 77（プランの実行も進行表と同じ 1 つの DB に置く）の見直し、ロック・破損・控え・消す時期、アプリの版と形の版、DBOS の版
- 含まない: プランの遷移・行き先の選び方そのもの（C2・C3）

## 起票者の推定

p6 のオーガナイザー（Claude Code）が、2026-11-14 の #1142 設計レビュー（実行時の観点）の指摘を分類 D としてまとめた。DBOS の取り出しの条件はオーガナイザーが 3.5.0 のリリース対象（wheel）でも確かめた。

## あるべき姿

1. DBOS の記録は実行の鍵ごとのファイルに分け、進行表だけを共有の DB に置く（または起動ごとに `application_name` を分ける）。2 つのプロセスで開いても相手のキューを取り出さないことをテストで確かめる
2. 共有の DB は開くときに `quick_check` し、backup API で控えを取る。~~20 プランと 14 ラッパー相当の負荷で詰まりを測ってから C2 をマージする~~ 書き手をそろえてから決めた回数を同時に書き、`database is locked` が 0 回であることを CI のテストで確かめてから C2 をマージする（#3291 の本文の B3。所要時間は合否にしない）
3. ワークフロー単位の退避と、何日で消すかの規則がある
4. 置き場の `format.json` は形の番号を持ち、合わなければ止めて置き場ごと退避する。レーンの起動時に計画の中の NDF の版がそろっているかを確かめる。版を上げる前に、待ちを抱えた実行の一覧を出す
5. DBOS は最新の安定版を使う（分類 G の依存の方針）

## 受け入れ条件

下の指摘がすべて、設計の差分（設計承認ゲートを通した PR）か子の受け入れ条件で解かれている。

- [ ] **1 つの DB で別のレーンがよそのキューを流す（critical）**: 決定 77（`issue-1142-design-next.md:221`、詳細設計 `:271`）は executor_id を進行表の行の ID にするが、DBOS の `start_queued_workflows` はキュー名・`application_name`・`app_version`（とパーティションキー）だけで絞り、executor_id では絞らない（3.1.0 の `dbos/_sys_db.py`、3.5.0 でも同じ）。前の設計の決定 26（`issue-1142-design-dbos.md:646-651`）・I17（`:90`）はこれを避けていた。承認ゲートで `os._exit` したプロセスの executor_id のまま PENDING で残る
- [ ] **詰まりと壊れたときの影響範囲**: DBOS の SQLite は全トランザクションを `BEGIN IMMEDIATE` で開き、キューの見回りが 1 秒ごと（`_sys_db_sqlite.py:41-48`、busy_timeout 30 秒）。設計に破損・`integrity_check`・控えの記述が無い
- [ ] **膨らみ続ける**: 今の鍵ごとの記録は `.git/ndf/state/dbos` に 2261 ファイル・680MB。URL を渡すと `purge_old`・`retire_if` を当てない。N1 の `retire`・N3 の作り直しはファイル単位の退避が前提
- [ ] **11.0.0-dev.N が出るたびに途中の実行が取り消される**: アプリの版はワークフローのソースから計算する（`dbos/_dbos.py:335-345`）。前の設計の決定 28 が退けた形。1 つの DB では版の違うレーンが同時に動けない（p6 では 10.27.59 と 10.27.60 が同時に動いた）
- [ ] **DBOS が 3.1.0（2026-09-24）のまま**: 最新の安定版は 3.5.0（2026-11-10）。キューまわり（sharded・パーティション）に変更があり、上げる前に変更点を読む
