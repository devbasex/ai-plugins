# コーディングルールskill作成

* python / javascript / typescriptなどでプログラムを作成する際の好みを反映するskill
* コーディング時の細微だが守りたいルール集
* リファクタリング時にも参照

## 基本方針は「コードよりもデータ」
* コードは基本原則のみを記述。判断やロジックは極力データとして表現する

## 分岐
* if文 / switch文 / case 文による分岐は極力避ける
* 特にif文、switch文のネストやelseによる多段構成は原則利用しない
* 配列、map、dictなどとポインタ、関数参照などを利用した分岐を優先する
* つまり、分岐は極力データで判断する

## ループ
* 多次元構造のscanをループで解決しない
* ベクトル、行列の問題として対応する(.map, .applyなど)
