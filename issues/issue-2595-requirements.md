## 目的

並列の計画のオーガナイザーのセッションを、ほかの conductor と同じ文脈の上限で切り替える。達成したい状態は次のとおりである。

オーガナイザーの文脈が上限を超えたら、知らせへの 1 手を終えた時点で hook が止め、オーガナイザーは引継ぎ文書を更新して `ndf-next` を出す。ラッパーがプラグインを更新して新しいセッションを起動し、新しいセッションは動いている耐久ワークフローをそのまま使って続ける。2026-11-04 15:00 JST に起動した計画 p3 のオーガナイザーは、この判定を一度も受けずに文脈が 800k トークンを超えた。

## 前提

- 前提 1: オーガナイザーはラッパーの下で動く。`parallel.py start` はラッパーの外では 3 で終わる（`development-workflow` の `references/parallel.md` の手順 1）
- 前提 2: 「答えていない問いが無い時点」は、オーガナイザーが知らせへの 1 手と答えの後の整理を終え、`wait` を打ち直す時点とする。`AskUserQuestion` の間は Bash を打てず、整理の手順は残りの問いを出してから `wait` を打つ。オーガナイザーがまだ読んでいない依頼は、耐久ワークフローの記録に残り、新しいセッションが受け取る（受け入れ条件 12）
- 前提 3: この課題は #2647 の計画の台帳を待たない。切り替えに要る `start` の付け直しと `wait --after 0` は今の `develop` にある。#2647 が先にマージされても、受け入れ条件は同じに読める
- 前提 4: 判定の対象を決める手がかりはコマンド（`parallel.py wait`）である。`wait` を打つのは手順上オーガナイザーだけで、役割の印を読まない
- 前提 5: 動いているオーガナイザーのセッションには、この変更が届かない。切り替わるまで古い hook で動くためである。今動いている計画は、リリースの後に人が `/ndf:restart` を 1 回打って切り替える（実行の前に未決の 1 で確かめる）
- 前提 6: Claude Code だけを対象にする。Codex には hook もラッパーも無い（`references/context-window.md`・`references/relay.md`）

## 起票時の記録

### 何が起きたか

並列の計画 p3 のオーガナイザーのセッション（`9518c67a-ba77-4d79-a685-4d16cbd7d63a`、2026-11-04 15:00 JST 起動）の文脈が 800k トークンを超えた。文脈の量による再起動（token の guard の拒否と `ndf-next`）は一度も掛からなかった。利用者が気づいて指摘した（2026-11-06）。

### 原因

1. **token の guard は「新しいフェーズの起動」でしか判定しない。** `hook_lib/token_guard.py` の `_launch_key` が判定の対象にするのは、次の 3 つだけである
   - Bash でプランを始めるコマンド（`shell_checks.starts_plan`）
   - 工程の一覧（`STAGES`）にある Skill
   - 説明が工程の接頭辞（`STAGE_PREFIXES`）で始まる Agent

   オーガナイザーが打つのは、`parallel.py wait`・`answer`・`confirm`・`settle`、`relay.py spawn`・`restart`、材料を読む `ndf:worker`（説明は自由な文）である。どれも対象外なので、判定は一度も起きない
2. **判定の記録は起動直後の 1 件だけ。** `~/.local/state/ndf/context/decisions/devbasex__ai-plugins.decisions.jsonl` のこのセッションの行は 1 行（2026-11-04T06:00:04Z）で、最初の `Skill(ndf:development-workflow)` の時点のもの。`context: null`・`basis: 値なし`・`relay: false` で通っている
3. **オーガナイザーのカットポイントが決まっていない。** `references/parallel.md` の「セッションの切り替え」は「カットポイントでは、問いを出していなければ引継ぎ文書を書き `ndf-next` を出して切る」と書く。しかし、オーガナイザーにとってどこがカットポイントかを定めていない。オーガナイザーの conductor も、自分から切らなかった
