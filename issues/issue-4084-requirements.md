## 由来

PR #4082 の cross-review の指摘 r1-1（major・`issues/issue-4045-design-detail.md:71`）と r1-2（major・`issues/issue-4045-design.md:207`）。PR #4082 は #4081（#4050 の設計の 10 点の穴）を直す設計 PR で、差分は `issues/issue-4050-*` の 3 ファイルだけである。#4045 の文書は受け入れ条件にも直す対象にも入らないので範囲外とした。#4045 は実装の前で、分けても片方だけが残る形ではない。根拠: Value 3「判断の要らない手順は仕組みが進めるので、結果が実行ごとにばらつかない」（MVV バージョン 11）

PR #4083 の cross-review の指摘 r1-1（major・`issues/issue-4045-design.md:207`）を 3 点目として足した。PR #4083 は #4051 の設計 PR で、差分は `issues/issue-4051-*` の 3 ファイルだけであり、#4045 の文書は範囲外である。2 点目と同じ原因（`kept_round` が例外を当てた入力を記録し、実際に渡った行と分けない）なので別の Issue にしなかった。根拠: Value 3「判断の要らない手順（…集計…）は仕組みが進めるので、結果が実行ごとにばらつかない」（MVV バージョン 11）

PR #4087（#4044 の設計）の cross-review の指摘 r1-4（major・`issues/issue-4045-design.md:207`。取り込み時の `kept_round` が、起動枠が空かずに渡らなかった行と見送り済みの再提出の行にも付き、受け入れ条件 7 の件数が過大になる）も 3 点目と同じ原因なので、ここへ由来を足した。PR #4087 の差分は `issues/issue-4044-*` だけで、#4045 の文書は範囲外である
