# 提案・企画

**読み手に採否の判断を求める。** まだ決まっていないことを提案する文書である。

## 必ず書く節

| 節 | 何を書くか |
| --- | --- |
| 提案の骨子 | **何をするか**を 1 文で。冒頭に置く |
| いま何が起きているか | 提案の前提になる事実。**数値には出典を付ける** |
| どう変わるか | 提案を採ったときの状態。採らなかったときとの差 |
| どう進めるか | 段取りと期間 |
| 費用と体制 | かかるもの。**概算なら語で区別する** |
| 決めてほしいこと | **読み手が何に答えれば前へ進むか**を明示する |

## 書かない節

| 書かないもの | なぜ |
| --- | --- |
| 検討の経緯 | 読み手は結論を判断する。過程は判断材料にならない |
| 不採用にした案の比較表 | 比較のためだけに並べない。**採否と理由**として 1 行で書く |
| 自社の会社紹介（社外向けで先方が既知のとき） | 読み手が求めていない |
| 提案の範囲外の将来構想 | 判断の対象が広がり、決められなくなる |

## 読み手が最初に問うこと

**「何をするのか、いくらか、いつまでか」。** この 3 つの答えを冒頭の 1 画面に置く。

社外向けでは**「なぜ自社に持ってきたのか」**が続く。相手の状況に触れずに一般論から入ると、
読み手は自分の話として読まない。

## よくある欠落

| 欠落 | 何が起きるか |
| --- | --- |
| 決めてほしいことが書かれていない | 読み終えても何も決まらない。次の会議がもう 1 回要る |
| 数値の出所が空 | 実在の提案資料で `参照元` の列の 20 行以上が空だった |
| 費用が総額だけ | 内訳が無いと、削る判断ができない |
| 採らなかったときの状態が無い | 提案を採る理由が相対的に見えない |
| 期間に前提が無い | 遅れたときにどこがずれるのか分からない |
