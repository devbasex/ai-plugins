# 説明・研修

**読み手に理解だけを求める。** 判断も操作も求めない。

## 必ず書く節

| 節 | 何を書くか |
| --- | --- |
| 何の話か | 対象と範囲。**冒頭に置く** |
| なぜ知る必要があるか | 読み手にとっての意味 |
| 中身 | 伝えること。**1 つの塊で 1 つのことを言う** |
| よくある誤解 | 読み手が別の意味に取りやすいところ |
| この後どうするか | 読み終えた後に何が起きるか（研修なら次回、方針なら適用の時期） |
| 問い合わせ先 | 分からないときの窓口 |

## 書かない節

| 書かないもの | なぜ |
| --- | --- |
| 決裁を求める節 | 判断を求めるなら別のタイプである |
| 手順の詳細 | 手を動かすなら運用マニュアルである |
| 検討の経緯 | 理解の助けにならない |

## 読み手が最初に問うこと

**「自分に関係があるか、何を覚えて帰ればいいか」。** 対象と、覚えて帰る要点を冒頭に置く。

## よくある欠落

| 欠落 | 何が起きるか |
| --- | --- |
| 対象が書かれていない | 自分に関係があるか分からず読み飛ばされる |
| 要点が最後にある | 途中で読むのをやめた人に何も残らない |
| よくある誤解が無い | 別の意味に取ったまま運用される |
| 適用の時期が無い | いつから守ればよいのか分からない |
| 質問の受け口が無い | 分からないまま放置される |
