# 定例報告

**決まった周期で同じ枠に値を入れる。** 読み手が見るのは**差分**である。

## 必ず書く節

| 節 | 何を書くか |
| --- | --- |
| 実績の要約 | 主要な指標の値。**前期との差を並べる** |
| 達成の状況 | 目標に対してどこにいるか |
| 前期との比較 | 何が変わったか。**変わった理由** |
| 課題 | 目標に届かないもの。**原因まで書く** |
| 次の打ち手 | 課題ごとに、誰が何をいつまでに |
| 進捗 | 前回の打ち手がどうなったか |

**節の並びを毎回変えない。** 読み手は同じ場所を見る。

## 書かない節

| 書かないもの | なぜ |
| --- | --- |
| 指標の定義 | **定義は別の文書が持つ**（指標定義）。毎回載せると、定義が版ごとに散る |
| 施策の詳細な手順 | 報告は結果を見る場である |
| 目標そのものの見直し | 定例の枠を超える。別の場で決める |

## 読み手が最初に問うこと

**「目標に届いているか、届いていないなら何をするか」。** 要約の冒頭にこの 2 つを置く。

## よくある欠落

| 欠落 | 何が起きるか |
| --- | --- |
| 前期との差が無い | 値だけでは良し悪しが分からない |
| 課題に原因が無い | 打ち手が症状に対するものになる |
| 前回の打ち手の進捗が無い | 同じ課題が毎回並ぶ |
| 打ち手に担当と期限が無い | 次回も同じ状態で出てくる |
| 値の出所が回ごとに違う | 比べられない。**出典の表を毎回同じ形で持つ** |
