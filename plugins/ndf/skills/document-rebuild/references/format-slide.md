# 文書形式: スライド

**この形式別ガイドは、発表資料（スライドとスピーカーノート）に当たる。** ページの文言の決まり（1 ページ 1 メッセージ・台本の文を縮めて載せない・見出しはページの結論・章扉）の本文は、`release` の [form-slide.md の「ページの文言を書く」](../../release/references/form-slide.md#ページの文言を書く) にだけある。このファイルは測り方だけを持つ。

## 文章量の単位と目安

**文章量の単位は 1 ページである。** 組み直しの対象は、構成メモ（ページごとの見出しと役割）と台本である。

| 指標 | 目安 | 根拠 |
| --- | ---: | --- |
| 1 ページのメッセージ | 1 つ | `form-slide.md` の「ページの文言を書く」 |
| 尺 | 持ち時間以内 | `form-slide.md` の台本の測り方（350 字/分） |
| 1 ページの字数 | 決めない | 未実測（試行の値で置き換える） |
| 章扉 | 章ごとに 1 ページ | `form-slide.md` の「ページの文言を書く」 |

**数えるものは、ページごとのメッセージの数・章扉の有無・台本の尺である。** 尺は `form-slide.md` の「台本を書き、尺を測る」の手段で測る。

## 題と見出し

**見出しはそのページの結論を短く書く。** 正本は `form-slide.md` の「ページの文言を書く」である。資料の題とキーワードは、読み手が社外なら [keyword-check.md](keyword-check.md) で公式ドキュメントの語と突き合わせる。

## 測らない指標

**平均文長・最長文・章あたりの行数は測らない。** ページには句と体言止めを置き、読み上げる文はスピーカーノートが持つ。

## 呼び出し先

| 何を | 呼び出し先 |
| --- | --- |
| ページの文言・構成メモ・台本・生成 | `release` の `form-slide.md` |
| 版面（縦横の比・書体・1 ページの情報量） | `design` の `layout-slide.md` |
| 生成物の版面の点検 | `layout-review` |
