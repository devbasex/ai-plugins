# 文書の目的: 小説

**物語を読み手へ渡す文書に当たる。** 小説・短編・物語。

## 見分ける手がかり

- 登場人物と場面があり、会話文を含む
- 呼び出し元が「小説」と指定した

## 構成

**構成を変えない。** 章・場面・文の順は物語そのものであり、組み直しで動かすと内容が変わる。

組み直しで行うのは、表記と語の揺れの統一だけである（共通ルール K6・K8）。人名・地名・用語の表記を 1 つにそろえる。

## 外す共通ルール

| 共通ルール | 外す理由 |
| --- | --- |
| K4（実物の例） | 物語は説明を目的にしない |
| K5（内部の語を持ち込まない） | 作中の語は物語の一部である |
| K7（断定しない） | 語りの断定は物語の一部である |
| K10（パス・URL） | パスと URL を持たない |

## 文章量

**文長・章の行数の目安は使わない。** 前後の値の表には測った値だけを残し、目安との比較をしない。

## 結論の位置

**指標「結論・成果物が定義される位置」は測らない（対象外）。**

## 文書タイプとの対応

対応する文書タイプは無い。
