# 文書の目的: エッセイ

**書き手の考えを、書き手の論の運びのまま読み手へ渡す文書に当たる。** 随筆・コラム・意見文。

## 見分ける手がかり

- 一人称の語りで、考えの移り変わりを順に書く
- 呼び出し元が「エッセイ」と指定した

## 構成

**書き手の論の運びを保つ。章と段落を入れ替えない。** 読み手は書き手の考えの順に読むことで納得するため、結論を先に置く並べ替えは目的に合わない。

組み直しで行うのは次の 2 つに限る。

| 行うこと | 行わないこと |
| --- | --- |
| 段落の中の長い文を分ける | 章と段落の並べ替え |
| 語と表記の揺れをそろえる（共通ルール K6） | 対比・列挙の表への置き換え |

## 外す共通ルール

| 共通ルール | 外す理由 |
| --- | --- |
| K7（確かめていないことを断定しない） | 書き手の考えを述べる文書で、断定は論の一部である |
| K10（パス・URL） | パスと URL を持たない |

## 文章量

**文長の目安は使わない。** 文の長さは書き手の文体である。最長文だけを測り、読み返して意味が取れない文を分ける。

## 結論の位置

**指標「結論・成果物が定義される位置」は測らない（対象外）。**

## 文書タイプとの対応

対応する文書タイプは無い。
