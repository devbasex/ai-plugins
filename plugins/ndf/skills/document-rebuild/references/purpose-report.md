# 文書の目的: 作業レポート

**行った作業・調査の結果を読み手へ渡す文書に当たる。** 作業報告・調査レポート・定例報告。

## 見分ける手がかり

- 期間か作業の範囲を区切り、その中で何をしたかを書く
- 目標・期待との差、実測、出力が並ぶ
- 文書タイプが定例報告

## 構成

| 順 | 章 | 読み手の問い |
| --- | --- | --- |
| 1 | 結果（目標との差） | 届いたのか、届いていないのか |
| 2 | 何をしたか | どの作業でその結果になったか |
| 3 | 根拠（実測・出力） | 結果はどこで確かめられるか |
| 4 | 未確認・残リスク | まだ分かっていないことは何か |
| 5 | 次の打ち手 | 次に何をするか |

**否定の結論（無かった・起きない）には、探した跡を添える。** 正本は `investigation-rules` の「否定的結論にはエビデンス必須」である。

## 文章量

形式別ガイドの目安に従う。この目的が足す目安は無い。

## 結論の位置

**指標「結論・成果物が定義される位置」は、「結果が最初の章」に読み替える。**

## 文書タイプとの対応

定例報告では、1 の章に `type-report.md` の「読み手が最初に問うこと」（目標に届いているか、届いていないなら何をするか）の答えを置く。
