# 英語の数え方

**この文書は英語で書かれた文書だけに当たる。** 他の言語は `lang-<言語>.md` が持つ。

## 文の区切り

**終止符と、その後ろに続く空白または行末の組み合わせで区切る。** 終止符だけでは区切らない。

| 形 | 例 | 区切るか |
| --- | --- | --- |
| `.` + 空白 + 大文字 | `... is required. The reader ...` | 区切る |
| `.` + 行末 | 段落の末尾 | 区切る |
| `?` `!` + 空白または行末 | `Why is it needed?` | 区切る |
| `.` + 空白 + 小文字 | `e.g. the reader` | 区切らない |
| 略語の中の `.` | `Inc.` `vs.` `i.e.` `e.g.` | 区切らない |
| 数字の中の `.` | `1.4` `v10.5` | 区切らない |

**略語の一覧は網羅ではない。** 判定できない形が出たら、その文書での扱いを決めて段 4 の表へ
残す。**扱いを決めずに数を出さない**（前後で扱いが変わると、値を比べられなくなる）。

### 区切らないもの

| 形 | 理由 |
| --- | --- |
| 見出しの行 | 終止符で終わらないため、そのまま 1 文として数える |
| 表の行 | セルは文ではない。**表は文長の集計に入れない** |
| コードブロックの中 | 文書の文ではない |
| 箇条書きの 1 項目 | 終止符が無ければその項目全体を 1 文とする |

## 字数の数え方

**語の数ではなく文字の数を数える。** 目安の値を日本語と共通にするためである。

| 対象 | 数えるか |
| --- | --- |
| 英数字・記号 | 数える |
| 語の間の空白 | 数える |
| 改行 | 数えない（1 文が複数行にわたるときは、改行を除き、空白 1 つで連結する） |
| 囲みの記号（`` ` `` `*` `_`） | 数えない |

**語の数を併記してよい。** 英語では語数のほうが読みやすさの目安として通りがよいため、
文字数の隣へ並べる。ただし**目安との突き合わせは文字数で行う**。

## 目安との突き合わせ

| 指標 | 数え方 |
| --- | --- |
| 平均文長 | 全文の字数の合計 ÷ 文の数 |
| 最長文 | 文ごとの字数の最大 |
| 章あたりの行数 | 見出しから次の同じ水準の見出しまでの行数（見出しの行を含む） |

**英語は同じ内容を日本語より多い文字数で書く。** そのため平均文長が目安（40 字）を超え
やすい。超えた項目は理由を残す手順に従い、**文字数の目安をこの文書で下げない**（目安を
言語ごとに変えると、前後の値を同じ尺度で読めなくなる）。
