# 文書形式: 表計算

**この形式別ガイドは、シートとセルで読ませる表計算（Excel・Google スプレッドシート）に当たる。**

## 文章量の単位と目安

| 指標 | 目安 | 根拠 |
| --- | ---: | --- |
| 1 シートの主題 | 1 つ | 未実測 |
| 要約の位置 | 先頭のシート | 未実測 |
| 1 セルの値 | 1 つ | 未実測 |

## 題と見出し

| 項目 | 決まり |
| --- | --- |
| シート名 | そのシートの主題を名詞句で書く |
| 列の見出し | 名詞と単位を書く（例: 「売上（千円）」） |
| 列の順 | `design` の `layout-spreadsheet.md` が決める |

## 測らない指標

**平均文長・最長文・章あたりの行数は測らない。** セルには文ではなく値を置く。文で書く説明は、要約のシートか注記の列に置き、そこだけ `format-markdown.md` の文長の目安を借りる。

## 呼び出し先

| 何を | 呼び出し先 |
| --- | --- |
| 版面（列の順・書式） | `design` の `layout-spreadsheet.md` |
| 生成とシートの区切り | `release` の `form-spreadsheet.md` |
| 生成物の版面の点検 | `layout-review` |
