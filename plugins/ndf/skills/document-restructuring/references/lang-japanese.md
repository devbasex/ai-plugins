# 日本語の数え方

**この文書は日本語で書かれた文書だけに当たる。** 他の言語は `lang-<言語>.md` が持つ。

## 文の区切り

**句点で区切る。** 区切りの文字は次の 3 つである。

| 文字 | 例 |
| --- | --- |
| `。` | 読み手が最初に知りたいのは結論である。 |
| `！` `？`（全角） | どこで区切るのか。 |
| `!` `?`（半角） | 半角で書かれた文も同じ扱いにする |

**区切りの直後が閉じ括弧のときは、括弧の外側までを 1 文とする。**
「〜である（実測）。」は 1 文で、括弧の中に句点があっても分けない。

### 区切らないもの

| 形 | 理由 |
| --- | --- |
| 見出しの行 | 句点で終わらないため、そのまま 1 文として数える |
| 表の行 | セルは文ではない。**表は文長の集計に入れない** |
| コードブロックの中 | 文書の文ではない |
| 箇条書きの 1 項目 | 句点が無ければその項目全体を 1 文とする |
| 3 点リーダ（`…`）と中黒（`・`） | 区切りではない |

**表とコードブロックを集計から外すのは、組み直しが散文を表へ移す作業を含むためである。**
表を集計へ入れると、表へ移した分だけ平均文長が下がって見える。

## 字数の数え方

**文字の数をそのまま数える。** 全角と半角を区別せず、どちらも 1 文字とする。

| 対象 | 数えるか |
| --- | --- |
| 漢字・かな・全角の記号 | 数える |
| 半角の英数字・記号 | 数える |
| 空白（半角・全角） | 数える |
| 改行 | 数えない（1 文が複数行にわたるときは、改行を除いて連結する） |
| 囲みの記号（`` ` `` `*` `_`） | 数えない（表示されない記号のため） |

**全角を 2 文字として数えない。** 目安の値（平均 40 字・最長 100 字）は、全角も半角も
1 文字として数えた実測から出ている。数え方を変えると目安と比べられなくなる。

## 目安との突き合わせ

| 指標 | 数え方 |
| --- | --- |
| 平均文長 | 全文の字数の合計 ÷ 文の数 |
| 最長文 | 文ごとの字数の最大 |
| 章あたりの行数 | 見出しから次の同じ水準の見出しまでの行数（見出しの行を含む） |

**1 文が長くなりやすい形が 3 つある。** 最長文が目安を超えたときは、まずこの 3 つを疑う。

| 形 | 直し方 |
| --- | --- |
| 「〜であり、〜であるため、〜になる」の連鎖 | 「〜である。そのため〜になる。」へ分ける |
| 括弧の中に条件を積む | 括弧の中を表の行へ移す |
| 対比を 1 文で述べる（「A は〜だが、B は〜である」） | 2 列の表へ移す |
