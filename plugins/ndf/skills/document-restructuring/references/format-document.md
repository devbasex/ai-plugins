# 文書形式: 文書

**この形式別ガイドは、ページ送りで読ませる文書（Word・Google ドキュメント・PDF）に当たる。** ソースが Markdown でも、読み手が文書として読むならこのファイルを読む。

## 文章量の単位と目安

| 指標 | 目安 | 根拠 |
| --- | ---: | --- |
| 平均文長 | 40 字以下 | 未実測（`format-markdown.md` の値を借りる） |
| 最長文 | 100 字以下 | 未実測（同上） |
| 1 節の長さ | 1 ページ以内 | 未実測 |

## 題と見出し

| 項目 | 決まり |
| --- | --- |
| 件名 | 主題と、読み手に求めることを入れる。一覧で見たときに判断の見当が付く形にする |
| 見出しの階層 | `design` の `layout-document.md` が決める |

## 測らない指標

**章あたりの行数は測らない。** 行数は版面（用紙・書体・余白）で変わり、ソースの行数とずれる。

## 呼び出し先

| 何を | 呼び出し先 |
| --- | --- |
| 版面（見出しの階層・書体・余白） | `design` の `layout-document.md` |
| 生成とページの区切り | `release` の `form-document.md` |
| 生成物の版面の点検 | `layout-review` |
