# 体裁設計: スライド

**読み手へ渡す文書を作るとき、出力の形がスライドなら読む。**

共通規則は [layout-common.md](layout-common.md) にある。このファイルではスライド固有の項目だけを
決める。

## 決める項目

| 項目 | 決めること |
| --- | --- |
| 縦横の比 | 16:9 か 4:3 か。投影する環境が決める |
| 余白 | 上下左右。**投影で切れる範囲を見込む** |
| 書体 | 見出しと本文。**配布先の環境にある書体か**を確かめる |
| 文字の大きさ | 見出し / 本文 / 注釈の 3 種類 |
| 色 | 地・文字・強調の 3 つ。**強調は 1 色に絞る** |
| 1 ページあたりの情報量 | **1 ページ 1 メッセージ。** 行数と図の数の上限 |
| ページの文言 | **台本の文を縮めて載せない。** 見出しはそのページの結論を短く、箱・表・箇条書きは短い句か体言止めにする。聞き手が知らない内部の語は、聞き手に通じる語へ言い換えるか、ページの中で一言で説明を添える |
| 章立て | **章扉で構成を見せる。** 章の名前と一言を決める。章扉はスピーカーノートを持たず、台本のページを消費しない |
| 図表の種類 | 使う図の種類と、使わない種類 |
| トーン＆マナー | 上の書体・色・文字の大きさに、著作権表示の文言とロゴの有無を加えた組。**既定は会社色を持たない汎用テンプレートの値**で、変える項目だけを決める |
| ページの枠組み | 見出し・罫線・ロゴ・著作権表示・ページ番号・注の位置。**汎用テンプレートの枠組みの座標を使い、資料ごとに決め直さない** |
| 構成 | ページごとの見出し・役割・根拠と、持ち時間に収まる尺（構成メモと台本。`form-slide.md`） |

**生成の経路は「生成スクリプトを書く」の 1 つである**（`release` の `form-slide.md`）。決めた値は設計文書の入出力の契約に
書き、トーン＆マナーは資料の `slides/theme.json` へ写す。項目名と既定値は汎用テンプレートの枠組み
（`release` の `assets/slides/lib/deck-frame.js` の `DEFAULT_THEME`）が持つ。

## 関連
