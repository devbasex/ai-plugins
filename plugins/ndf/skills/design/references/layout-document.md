# 体裁設計: 文書

**読み手へ渡す文書を作るとき、出力の形が文書なら読む。**

共通規則は [layout-common.md](layout-common.md) にある。このファイルでは文書固有の項目だけを
決める。

## 決める項目

| 項目 | 決めること |
| --- | --- |
| 判型 | A4 か Letter か。印刷するかどうかで決まる |
| 余白 | 上下左右。**綴じる場合は綴じ代を見込む** |
| 書体 | 見出しと本文。**配布先の環境にある書体か**を確かめる |
| 文字の大きさと行間 | 見出し / 本文 / 注釈の 3 段 |
| 色 | 地・文字・強調の 3 つ。**印刷するなら白黒でも読めるか**を見る |
| 1 ページあたりの情報量 | 見出しの階層の深さと、1 節の長さの上限 |
| 図表の種類 | 使う図の種類と、使わない種類 |
| 改ページ | 節の途中で切らない箇所（表・図・手順） |
| 生成の経路 | 変換器か、AI エージェントか |
