# 体裁設計: ページ

**読み手へ渡す文書を作るとき、出力の形がページなら読む。**

共通規則は [layout-common.md](layout-common.md) にある。このファイルではページ固有の項目だけを
決める。

## 決める項目

| 項目 | 決めること |
| --- | --- |
| 見出しの階層 | 何段まで使うか。**深いと目次から辿れなくなる** |
| 本文の幅 | システムが決めることが多い。**変えられるかを先に確かめる** |
| 書体と文字の大きさ | システムの既定を使うか、変えるか |
| 色 | 地・文字・強調の 3 つ |
| 1 ページあたりの情報量 | ページを分ける基準 |
| 図表の種類 | **システムが描画できる形式で決まる**（`document-systems` の `system-<名前>.md`） |
| 目次と索引 | 自動生成に任せるか、手で置くか |
| 生成の経路 | 変換器か、AI エージェントか |
