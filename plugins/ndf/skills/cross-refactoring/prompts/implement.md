# リファクタリングの実装（cross-refactoring / $RF_RUNTIME）

あなたは **$RF_RUNTIME**（モデル: $RF_MODEL）として、リファクタリング計画で採った改善項目を
**順位の順に 1 件ずつ**適用します。**振る舞いを変えずに構造だけを直します。**

## 必須コンテキスト

- リポジトリ: $RF_REPO / Pull Request #$RF_PR
- 作業ディレクトリ: `$RF_WORKDIR`（**ここでだけ作業する**）
- ブランチ: `$RF_HEAD_BRANCH`（base は `$RF_BASE_BRANCH`）
- 対象範囲: `$RF_SCOPE`

## 手順書

$RF_SKILL_BLOCK

## 適用する項目（順位の順）

```json
$RF_ITEMS
```

- `start_deadline` は**その項目に着手してよい最後の時刻**です。**過ぎたら着手せず、
  終えてください**（後ろの項目ほど締め切りが遅いので、順に進めれば間に合う形に
  組んであります）。完了期限（着手期限 + `estimate_minutes`）を過ぎた
  コミットはマージ処理で採られず、項目ごと見送られます
- `test_command` はオーケストレーターがこの項目の検証に走らせるテストです

## やること

項目ごとに次を行います。

1. `plan` の手順を適用する
2. `test_command` を実行し、通ることを確かめる。落ちたら原因の手を戻す。
   直せないならその項目の変更を戻して次へ進む
3. **その項目の変更を 1 つのコミットにする**（1 改善項目 = 1 コミット）

**テストの期待値を変えないでください。** 期待出力を変えたコミットの項目は取り消されます。

## コミットの規約

```text
Refactor: extract_method — src/foo/bar.py#BarService.handle

（変更の説明）

Item-Id: I-001
Impl-Runtime: $RF_RUNTIME
Impl-Model: $RF_MODEL
```

- **`Item-Id` が項目とコミットを結ぶ唯一の手がかりです。** リファクタリング計画に無い `Item-Id`、
  または `Item-Id` の無いコミットは取り消されます
- **1 項目に 2 コミット以上作らない。** 刻みたいときは、着手する前の HEAD を控えて
  おき、最後に `git reset --soft <控えた HEAD>` してから 1 回だけコミットする
- `Impl-Model` には**実際に使ったモデル名**を書く。分からなければ `default`
- **3 つのトレーラーはメッセージの最後の段落に置く。** 帰属行を足すときは空行を
  挟まず同じ段落に続けます

## 作業の進み具合を残す

**作業段階が進むたびに `$RF_STEM-progress.log` へ 1 行追記してください**
（`start` / `edit` / `test` / `commit` / `done`）。テストの実行中は何も出力されないため、
追記が無いと監視が「進んでいない」と見て打ち切ります。

## 守ること

- **push しない。** 公開するのはオーケストレーターだけで、**検証を通した後**に行います
- **`git push --force` と `--no-verify` を使わない**
- **テストは前景で実行し、終わるまで待つ**
- コミット時のフックが生成物の同期を求めても同期しない。フックが原因でコミットできない
  ときは `git -c core.hooksPath=/dev/null commit ...` で**そのコミットだけ**フックを外す
- **対象範囲（`$RF_SCOPE`）の外にあるファイルを 1 つも変更しない。** 範囲外を触った
  コミットの項目は取り消されます
- **生成物・配布物の同期をしない。** 同期はオーケストレーターが公開の直前に行います
- **機能変更を混ぜない。** 振る舞いを変える修正が要ると分かったら、その項目は適用しない
- 提案された手順の範囲を超えない。ついでの整理をしない
- 直した内容は必ずコミットする。worktree に置いたままの変更は捨てられます

## 提出形式

結果を **`$RF_STEM-result.json`** に書いてください。**オーケストレーターは git だけを見ます**
（何と書いてもチェック結果は変わりません）。

```json
{"items": [{"item_id": "I-001", "status": "done"}, {"item_id": "I-003", "status": "skipped", "reason": "振る舞いを変えないと直せない"}]}
```
