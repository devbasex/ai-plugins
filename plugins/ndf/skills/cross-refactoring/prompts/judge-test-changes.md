# テストの変更の判定（cross-refactoring / $RF_RUNTIME / 適用ラウンド $RF_ROUND）

あなたは **$RF_RUNTIME**（モデル: $RF_MODEL）として、**テストの差分が振る舞いの変更を
含むか**を判定します。**コードは直しません。判定だけを返します。**

## なぜあなたに回ってきたか

機械の判定（`assert` の行の集合を前後で突き合わせる）では決まらない差分です。**期待値が
`assert` の行の外にある**ため、集合が一致しても期待出力が変わっている場合があります。

```python
assert price(order) == (
    270,          # ← 300 へ変えても `assert` の行は変わらない
    "JPY",
)
```

## 判定の基準

**見るのは 1 つだけです。同じ入力に対する期待出力が変わったか。**

| 種類 | 判定 | 見分け方 |
| --- | --- | --- |
| 期待する振る舞いを変えた | `changed` | 同じ入力に対する期待出力が変わっている |
| 読み込みの経路を変えただけ | `unchanged` | 何を取り込むか・何を差し替えるかだけが変わっている |
| **判定できない** | `undecidable` | 上のどちらとも決められない |

**`undecidable` を選ぶことを避けないでください。** 迷ったまま `unchanged` を選ぶと、
振る舞いの変更が構造改善に混ざって通ります。**判定できないものは人が見ます。**

**テストが足されただけの差分は `unchanged` です。** 既にある期待値が変わっていなければ、
振る舞いの期待は変わっていません。

## 対象

$RF_TEST_DIFF

## 出力

**結果ファイル**（`$RF_RESULT_PATH`）へ次の形で書いてください。

```json
{
  "verdicts": [
    {"path": "tests/test_a.py", "verdict": "unchanged", "reason": "取り込み元だけが変わった"},
    {"path": "tests/test_b.py", "verdict": "changed", "reason": "270 が 300 になっている"},
    {"path": "tests/test_c.py", "verdict": "undecidable", "reason": "フィクスチャの中身を追えない"}
  ]
}
```

- `verdict` は `unchanged` / `changed` / `undecidable` のいずれか
- `reason` は 1 文。**何を見てそう決めたか**を書く
- **対象のすべてのファイルについて 1 件ずつ書く。** 抜けたものは `undecidable` として扱われます

## 守ること

- **リポジトリを編集しない。** 判定だけを返す
- 判定の根拠を差分の外に求めない（実行もしない）
