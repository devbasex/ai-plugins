# 「やらない」と決める

課題そのものは成り立つが、抱える費用が直す費用を下回るときに選ぶ。**「閉じてよい」とは
別である。** 前者は成り立つ課題を、後者は成り立たなくなった課題を閉じる。後から検索した
ときに区別が要るため、同じ判定にまとめない。

## 2 つの必要条件

**2 つとも満たしたものだけを候補にする。** どちらかが欠ければ、その課題は右端の行き先へ倒す。

| # | 条件 | 確かめ方 | 欠けたときの行き先 |
| --- | --- | --- | --- |
| 1 | 抱える費用が、直す費用を下回る | **実害の規模と頻度**を本文と由来から読む。**直す費用**は本文が指す箇所を実物で数える（触るファイル数）。その課題が原因で起きた手戻りの回数も数える | 既存の判定のまま |
| 2 | 同じ原因の他の課題へ寄せられない | 段 2B の重複の突き合わせの結果を使う | 重複 |

**どちらも見積りである。見積れないときは「要判断」へ倒す。**

**実害があっても「やらない」を選べる。** 稀にしか起きない事象に費用を掛けるのは無駄である。
決めるのは実害の有無ではなく、**規模と頻度が直す費用に見合うか**である。

**行き先が決まっていないことは、やらない理由になる。** 指す対象がこの先どうなるか決まって
いないなら、決まってから考えればよい。再燃の条件へ「行き先が決まったとき」と書いて閉じる。

## 重要度が、抱える費用の目安になる

**条件 1 の「抱える費用」を表しているのが重要度である。** ラベルの説明が実害の有無と規模で
区分を作っているためで、費用の見積りとは別の軸ではない。

| 重要度 | 抱える費用 | 候補になるか |
| --- | --- | --- |
| **高い**（実害・安全機構の欠落） | 大きい | **原則ならない。** 候補にするなら、実害が稀であることを実測で示す |
| 中くらい（保守性・設計一貫性） | 中くらい | 直す費用が大きければ候補になる |
| 低い（余力があれば） | 小さい | 候補になりやすい |

**重要度は先に見直す。** ラベルの説明に照らして付け替えてから、費用の見積りへ進む。起票の
時点の重要度のまま費用と比べると、比較の一方が古い値になる。

**高いものを候補にするときは、頻度を実測で示す。** 「稀にしか起きない」を根拠にするなら、
どれだけの機会のうち何回起きたかを書く。示せなければ**要判断**へ倒す。実害の記述がある
課題を見積りだけで閉じると、安全機構の欠落が根拠なく落ちる。

**重要度の低さそのものは理由にならない。** 滞留の期間で候補へ上げる形も採らない（期間の
根拠となる実測がまだ無い）。決めるのは上の 2 つの必要条件だけである。

## 再燃の条件は、観測できる形で書く

**「やらない」は保留であって終点ではない。** 費用の見合わなさは状況で変わるため、変わったと
分かる形で書く。

| 書き方 | 例 |
| --- | --- |
| **観測できる** | 同じ事象が 2 度目に起きたとき / 対象の行き先が決まったとき / 触るファイルが 3 つ以下になったとき |
| 観測できない | 頻度が上がったとき / 重要になったとき / 余裕ができたとき |

観測できない条件で閉じると、再び考える機会が来ない。**その課題は終点へ落ちる。**

## 候補を提示して承認を得る

**段 2B の後、段 3 の反映の前に 1 度だけ提示する。** 件ごとに聞かない。

| 列 | 何を書くか |
| --- | --- |
| 番号 | 課題の番号 |
| 実害 | 規模と頻度、確かめた場所 |
| 寄せ先 | 同じ原因の課題があるか |
| 費用の見積り | 触るファイル数と、その課題が原因で起きた手戻りの回数 |
| 再燃の条件 | 再び考える条件 |

**人が外したものは「要判断」へ戻す。** 承認されたものだけを段 3 が閉じる。

## 閉じ方

理由と再燃の条件は**本文の末尾へ書く**。GitHub の既定の検索は title と body を対象にし、
コメントを含まないため、コメントへ書くと後から拾えない。

```markdown
## やらないと判断した（2026-09-04）

- 実害: <規模と頻度、確かめた場所>
- 費用の見積り: <触るファイル数と手戻りの回数>
- 再び考える条件: <観測できる形で>
```

そのうえで `wontfix` を付け、`gh issue close <番号> --reason "not planned"` で閉じる。

**閉じた課題を棚卸の対象へ戻さない。** 戻すと対象の件数が下がらず、手入れの費用が減らない。
