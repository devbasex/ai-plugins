# Google Drive

**このリポジトリで実行して確かめた。** 取得は MCP の `read_file_content` で動く。

## 認証

| 経路 | 出所 |
| --- | --- |
| MCP | 利用者のセッションが持つ。設定は要らない |
| スクリプト（`google-drive` の `gdrive_fetch.py`） | OAuth2 のトークン。置き場所と作り方は `google-auth` が持つ |

**値は宣言に書かない。** `.ndf/document.json` の `auth` に書くのは環境変数の名前だけである。

**スクリプトの経路はトークンが無いと動かない。** 実測ではトークンが未設定で失敗した。
継続的統合で動かすなら、その前提を先に用意する。

## 取り込みの手段と取れないもの

| 対象 | 手段 |
| --- | --- |
| Google スライド | MCP の `read_file_content` |
| Google ドキュメント | 同上 |
| Google スプレッドシート | 同上 |
| PDF へ変換して取得 | `gdrive_fetch.py --mime application/pdf` |

**取れないもの。**

| 取れないもの | 影響 |
| --- | --- |
| スライドの区切り | 10 枚が 1 続きのテキストになる。**ページ番号が本文へ連結する**（`© … / Confidential2` のような形） |
| 改行 | 段落の区切りが失われ、全体がほぼ 1 行になる |
| 版面・図形の位置・大きさ・色 | **体裁は取れない。** 描画して見る |
| 図そのもの | 参照だけを残す |
| コメント | `includeComments` を渡しても出なかった。**未確認**（対象にコメントが無かった可能性がある） |

正規化は [import.md](import.md) が定める。

## 投稿の手段

**Markdown から Google スライド / ドキュメントを作る手段は、この Skill には無い。**
`google-drive` が持つのはアップロードと共有で、変換は持たない。生成の経路は
`release` の `form-<出力の形>.md` が決める（変換器を使うか、AI エージェントが組むか）。

**アップロードと共有は `google-drive` が持つ。** 内容をここへ写さない。

## 本文の表現

Google のネイティブ形式（スライド / ドキュメント / スプレッドシート）である。
**Markdown をそのまま受け取らない。** 変換した結果を上げる。

## 版の扱い

**Drive は版を保持する。** 同じファイルを更新すると版が増え、前の版へ戻せる。
**ただし「その状態を見た人」は戻らない。**

## 図の扱い

図は画像として貼る。**Mermaid をそのまま描画しない。** 画像へ変換してから貼る。

## 描画して見る手段

`gdrive_fetch.py --mime application/pdf` で PDF にしてから、ページを画像へ変換する。
**体裁レビューはこの経路を使う。**

## 既知の失敗

| 事象 | 対処 |
| --- | --- |
| `gdrive_fetch.py` がトークンの不在で失敗する | `google-auth` の手順でトークンを作る |
| 取り込んだテキストがほぼ 1 行になる | 正規化する（[import.md](import.md)） |
| ページ番号が本文へ連結する | 同上 |
