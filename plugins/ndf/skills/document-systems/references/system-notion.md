# Notion

**このリポジトリで実行して確かめた。** 取得は MCP の `notion-fetch` で、構造つきの Markdown が
返る。

## 認証

| 経路 | 出所 |
| --- | --- |
| MCP | 利用者のセッションが持つ。設定は要らない |

**MCP の経路が動く。** Confluence と違い、認証で失敗する事象は観測していない。

## 取り込みの手段と取れないもの

| 対象 | 手段 |
| --- | --- |
| ページ | MCP の `notion-fetch` |
| データベースの行 | `notion-query-data-sources` |

**取れたもの。** 見出し・表（XML 形式）・強調・ページのプロパティ。

**取れないもの。**

| 取れないもの | 影響 |
| --- | --- |
| 版面（幅・色・カバー） | **体裁は取れない。** 描画して見る |
| 埋め込みの外部コンテンツ | 参照だけが残る |
| コメント | **未確認** |

## 投稿の手段

**`notion-writing` が持つ。** 内容をここへ写さない。要点だけを挙げる。

- 本文は Notion 向けの Markdown で書く。**表は XML で、列幅を固定する**
- **更新は子ページを消さない形で行う**

## 本文の表現

Notion 向けの Markdown（`notion-writing` が定める）。**GitHub の Markdown と同じではない。**

## 版の扱い

**ページは上書きされる。** Notion 側の履歴で戻せるが、**「その状態を見た人」は戻らない**。

## 図の扱い

Mermaid のコードブロックを描画する。**画像へ変換しなくてよい。**

## 描画して見る手段

**未確認である。** 公開したページの URL を `playwright-kit` の `playwright-evidence` で撮る
案がある。**手段が無いときの倒し方は `layout-review` が持つ**（描画できないときは止める）。

## 既知の失敗

| 事象 | 対処 |
| --- | --- |
| 更新で子ページが消える | `notion-writing` の更新の手順に従う |
| 表の列幅が崩れる | 同上（XML で幅を固定する） |
