# 素材の収集と出典の確定

**文書に載せる数値・図・引用の出所を、書く前に確定させる。**

**開発では正しさをテストが測るが、文書では出所が正しさを支える。** 出所の無い数値は、
読み手が確かめられない。

## この Skill が持たないもの

**取得の手段を持たない。** 決めるのは**出所の残し方**だけである。

| 何を | どこが持つか |
| --- | --- |
| Google Drive からの取得 | `google-drive` |
| システムごとの取得の手順 | `document-systems` の `system-<名前>.md` |
| SQL による集計 | 対象リポジトリの手段（`ndf:data-analyst` エージェントなど） |
| 書かれた値と出所の突き合わせ | **`quality-gates` の事実確認の段**（この Skill ではない） |

**取得の手段を持つと、システムが増えるたびにこの Skill が太る。**

## 出典は本文の節に置く

**`## 出典` の節を文書の末尾に置く。** 生成物へそのまま載る場所を選ぶ。

| 置き場所 | 採否 | 理由 |
| --- | --- | --- |
| 本文の `## 出典` の節 | **採用** | 生成物に載る。読み手が確かめられる |
| frontmatter | 不採用 | 生成の経路で落ちる |
| 別ファイル | 不採用 | 生成物に含まれない |

## 出所として残す 4 項目

**URL だけでは同じ値へ戻れない。** スプレッドシートは値が後から変わり、画面は絞り込みの
条件で表示が変わる。

| 項目 | 何を書くか |
| --- | --- |
| 場所 | URL、またはシステムと識別子 |
| 位置 | シート名とセル範囲、クエリ、画面の絞り込み条件 |
| 時点 | 取得した日時 |
| 手段 | 画面 / クエリ / API のどれで取ったか |

書き方と、値と出典を結ぶ印は
[references/source-record.md](references/source-record.md) にある。

## 出所の無い値を拒否しない

**拒否すると、見込みと概算を書けなくなる。** 実在の文書は将来の値を扱う。代わりに**語で
区別する**。

| 語 | 意味 | 出所 |
| --- | --- | --- |
| 実績 | 確定した値 | **必須** |
| 見込み | 将来の値 | 要らない。**代わりに前提を書く** |
| 概算 | 精度を落とした値 | 要らない。**代わりに前提を書く** |

**3 つのどれかを必ず付ける。** 付いていない数値は、読み手が実績と読む。

**見込みと概算の前提は、後から成否を判定できる文で書く。**「前提: 現在の月次の伸び率
（前月比 8%）が 3 か月続く」のように、外れたと分かる形にする。

## 手順

### 1. 使う値を洗い出す

**構成案が決めた章立てを読み、各節が必要とする値を並べる。** 書きながら集めると、
出所を後から思い出せない値が混ざる。

### 2. 取ってくる

取得の手段は上の表の担当が持つ。**この Skill は手段を選ばない。**

### 3. 出典の節へ記録する

4 項目をその場で書く。**「後で書く」と決めた出典は埋まらない。** 実在の提案資料には
`参照元` の列があり、20 行以上が空のまま提出されていた。

### 4. 値へ区別の語を付ける

実績 / 見込み / 概算のどれかを本文の側へ付ける。

## 一致しなかったとき

**事実確認（`quality-gates` の段）で値と出所が食い違ったら、この工程へ戻る。**
本文の値を出所に合わせて直すのではなく、**どちらが正しいかを出所を取り直して決める**。
取り直した結果、出所の側が変わっていたなら、時点を更新して両方を直す。

## 範囲外の課題を見つけたとき

**出所を当たる過程で、この文書の範囲外の問題（数値の定義の食い違い、集計の誤りなど）に
気づいたら、その場で `/ndf:out-of-scope` が issue にする。**

この工程に入ったら `/ndf:progress-tracking <issue番号> "素材の収集と出典の確定"` を呼ぶ
（記録の手順はその Skill が持つ）。

## 関連

- `/ndf:quality-gates` — 事実確認（書かれた値と出所の突き合わせ）
- `/ndf:document-drafting` — 執筆（何を書くか）
- `/ndf:document-systems` — システムごとの取得の手順
- `/ndf:out-of-scope` — 範囲外と判断した課題の起票
