# 出典の書き方

## 節の形

**文書の末尾に `## 出典` を置く。** 表の 1 行が 1 つの出所である。

```markdown
## 出典

| # | 使った場所 | 場所 | 位置 | 時点 | 手段 |
| --- | --- | --- | --- | --- | --- |
| 1 | 「実績の推移」の表 | <広告管理画面の URL> | 期間 2026-06-01〜2026-08-31 / 指標: 費用・獲得数 | 2026-09-01 10:12 | 画面 |
| 2 | 「単価の内訳」の図 | <スプレッドシートの URL> | シート `2026Q2` の `B2:F40` | 2026-09-01 10:20 | 画面 |
| 3 | 「解約率」の値 | データ基盤 | クエリは付録 A | 2026-09-01 11:05 | クエリ |
```

**本文からは番号で指す。**「解約率は 4.2%（実績、出典 3）」のように書く。

## 4 項目の書き方

| 項目 | 良い例 | 足りない例 |
| --- | --- | --- |
| 場所 | 対象を一意に指す URL、またはシステム名と識別子 | 「管理画面」（どの画面か決まらない） |
| 位置 | シート名とセル範囲 / クエリ / 絞り込みの条件 | 空欄（同じ値へ戻れない） |
| 時点 | 日付と時刻 | 「8 月」（月内のいつか決まらない） |
| 手段 | 画面 / クエリ / API | 空欄（再取得の方法が決まらない） |

**クエリが長いときは付録へ置き、位置の欄からは付録を指す。** 表の中へ改行を含む長い文を
入れると、生成した表が崩れる。

## 区別の語

**本文の値の側に付ける。** 出典の表ではなく、読み手が値を読む場所に置く。

```markdown
- 獲得単価は 12,400 円（実績、出典 1）
- 来期の獲得単価は 11,000 円（見込み。前提: 現在の改善率が 2 四半期続く）
- 影響を受ける顧客は 300 社程度（概算。前提: 契約区分 A と B の合計に対する比率で見積もった）
```

**見込みと概算の前提は、後から成否を判定できる文で書く。**

## よくある欠落

| 欠落 | 何が起きるか |
| --- | --- |
| 出典の欄はあるが空 | 読み手は確かめられない。実在の提案資料で 20 行以上が空だった |
| 時点が無い | 値が変わった後、どの時点の値なのか分からない |
| 位置が無い | 同じ URL を開いても違う値が出る |
| 区別の語が無い | 見込みが実績として読まれる |
| 図の出所が無い | 数値には出典を付け、図には付けない例が多い。**図も出所を持つ** |
