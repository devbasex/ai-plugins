# リリースの形: デスクトップアプリ（Windows・macOS など）


アーティファクトを利用者が導入するもの。パッケージに近いが、署名とデプロイチャネルが加わる。

- **起点**: 直前の版のタグ
- **公開**: アーティファクトへ署名して置く。**署名が無いと利用者の環境が導入を拒む**ため、署名は公開の
  一部であって後回しにできない。ストアを経る場合は [form-mobile.md](form-mobile.md) も読む
- **リリース完了の確認**: デプロイ先に署名済みのアーティファクトが置かれ、取得できる。デプロイ先の一覧を引き、置かれた
  アーティファクトの署名を検証する
- **取得**: 利用者が導入する。自動更新の仕組みがあるなら、それが配る時期も書く
- **取り消し**: 新しい版を出す。**導入済みの環境は戻らない。** 自動更新で下げられるかは
  仕組みによる。戻せない前提で公開の同意（`ndf-gate:2`）を取る
