# 配布の形: デスクトップアプリ（Windows・macOS など）


配布物を利用者が導入するもの。パッケージに近いが、署名と配布チャネルが加わる。

- **起点**: 直前の版のタグ
- **公開**: 配布物へ署名して置く。**署名が無いと利用者の環境が導入を拒む**ため、署名は公開の
  一部であって後回しにできない。ストアを経る場合はモバイルアプリの項も読む
- **取得**: 利用者が導入する。自動更新の仕組みがあるなら、それが配る時期も書く
- **取り消し**: 新しい版を出す。**導入済みの環境は戻らない。** 自動更新で下げられるかは
  仕組みによる。戻せない前提で公開の同意を取る
