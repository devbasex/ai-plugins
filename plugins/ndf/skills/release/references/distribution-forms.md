# 配布の形ごとの手順

`release` の手順は形に依らない。**形ごとに変わるのは、起点の決め方・公開の仕方・取得の
手順・取り消し手段の 4 つ**である。ここでは形の選び方と、形をまたぐ決まりだけを書く。**手順は形ごとの
ファイルにある。対象の形のファイルだけを読む。**

対象がどの形にあたるかは `SKILL.md` の「配布の形」で決める。当てはまるものが無ければ、
最も近い形の考え方を借り、違うところを完了報告へ書く。

## 形ごとの一覧

| 形 | 起点 | 検証への配布 | 本番への配布 | 取得 | 取り消し |
| --- | --- | --- | --- | --- | --- |
| パッケージ・プラグイン | 直前の版のタグ、または版数を書き込んだコミット | 開発版と分かる版数で公開 | 正式版としてレジストリへ公開 | 利用者が取得する | 新しい版を出す |
| サービス | 直前に反映したリビジョン | 検証環境へ反映 | 本番環境へ反映 | **無い**（反映で届く） | 前のリビジョンへ戻す |
| デスクトップアプリ | 直前の版のタグ | 開発版のチャネルへ置く | 正式版として署名して置く | 利用者が導入する | 新しい版を出す |
| モバイルアプリ | 直前の版のタグ | 内部テスト・クローズドテストへ配る | ストアへ提出し、審査を経て公開 | 利用者が更新する | 段階的公開を止める |
| 手順・設定 | 直前に配った版 | 一部の利用者へ先に配る | 全員へ配る | 利用者が読む | 前の版を配り直す |

**本番への配布は、どの形でも承認を得てから行う**（`SKILL.md` の「配布の段階」）。この表の
「検証への配布」までが、工程の続きとして進めてよい範囲である。

## 開発版と分かる形で公開する

パッケージ・プラグイン・デスクトップ・モバイルは、**検証のための配布も利用者から見える場所へ
出ることがある**。正式版と取り違えられないよう、版数で開発用だと分かるようにする。

| やり方 | 例 | 向く場面 |
| --- | --- | --- |
| 接尾辞を付ける | `1.4.0-dev.3` / `1.4.0-rc.1` / `1.4.0-beta` | レジストリが事前公開の版を区別できる場合。多くのレジストリは既定の取得先から外す |
| 版数の帯を開発用に充てる | `1.5.x` を開発用、`1.6.x` を正式版（奇数を開発用にする慣習） | 接尾辞を扱えない配布先。番号だけで区別が付く |
| 配布の経路を分ける | 開発版のチャネル / 内部テストの配布先 | ストアや自動更新の仕組みが経路を持つ場合 |

**どれを採るかは配布先が決める。** レジストリが事前公開の版を既定の取得先から外すなら接尾辞が
素直で、そうでなければ帯か経路を分ける。**選んだやり方を完了報告へ書く。** 書かないと、次に
配布する人が別のやり方を採り、利用者から見て規則が無くなる。

**開発版の版数を正式版へ流用しない。** `1.4.0-rc.1` を確かめた後に出す正式版は `1.4.0` で
あって、`-rc` を外しただけの同じ中身とは限らない。確かめた対象と出す対象が違うなら、
`release-verification` は正式版に対してやり直す。

## 形ごとのファイル

**対象の形のファイルだけを読む。** 他の形の手順はコンテキストへ載せない。

| 形 | ファイル |
| --- | --- |
| パッケージ・プラグイン（**エージェントプラグインもここ**。Claude Code / Codex / Kiro） | [form-package-plugin.md](form-package-plugin.md) |
| サービス（Web アプリ・API・フロントエンド） | [form-service.md](form-service.md) |
| デスクトップアプリ | [form-desktop.md](form-desktop.md) |
| モバイルアプリ | [form-mobile.md](form-mobile.md) |
| 手順・設定の変更 | [form-procedure.md](form-procedure.md) |

**エージェントプラグインをサービスや手順・設定へ分類しない。** 利用者が取得の操作をして
受け取るため、パッケージ・プラグインにあたる。版数ではなく git の ref で取得する版が
決まる点が他と違い、その扱いは `form-package-plugin.md` の末尾にある。

形を追加するときも、他のファイルは変更しない。この表へ 1 行足し、ファイルを 1 つ増やす。
