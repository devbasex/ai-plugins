# 配備の完了を確かめる

公開の操作が済んだことを確かめる決まりのうち、**形で変わらないもの**をここに置く。形ごとに
何を照会するかは `form-<形>.md` の「完了の事実」にある。

**公開の操作がその場で終わるなら、この文書は読まなくてよい。** 読むのは、操作が終わるまで
待つ必要があるときである。

## 用語

| 語 | この文書での意味 |
| --- | --- |
| 公開の操作 | `SKILL.md` の手順 4 で実行する操作。レジストリへの公開・配備先への反映・署名した配布物の設置・ストアへの提出 |
| 完了の事実 | 公開の操作が済んだことを、**配布先の状態から読み取れる値**。レジストリの登録時刻、配備先が返す版数、ストアの提出物の状態 |
| 打ち切り | 待つのをやめること。**成否の判定とは別の判断**である |
| ログ | 公開の操作が書き出す文字列。実装の都合で変わる |

**成否は完了の事実で決め、ログは打ち切りの合図に使う。** この 2 つを分けずに書くと、ログに
出ると見込んだ語が出ないだけで待ちが残る（#228 の事例）。

## ログで判定するときの決まり

外部の事実を照会する手段が無い場合に限り、ログを見る。

| 決まり | 扱い | 内容 |
| --- | --- | --- |
| 完了の語と失敗の語を、先に 1 度流して確かめる | 必須 | 見込みで書かない。#228 の事例では、待っていた語が完了の行に出なかった |
| ログでの判定は打ち切りの合図に使い、成否の根拠にしない | 必須 | 打ち切った後に、その形の完了の事実を照会して成否を決める |
| 見張る対象を 3 つ持つ（完了の語・失敗の語・出力が増えない時間） | 推奨 | 完了の語だけを見張ると、失敗・停止・実行中のどれもが「まだ終わらない」になる |

**3 軸の見張りを推奨に置けるのは、待ちの上限が必須だからである。** 上限に達すれば打ち切られ、
完了の事実の照会へ移る。3 軸を持たない場合に失うのは、早く打ち切れることだけである。

## 3 軸を見張るときの雛形

そのまま貼って使う。**再起動・pidfile・結果ファイルの規約は持たず、ログの読み取りだけを行う。**

```bash
# $LOG は追記されるログ、$DONE と $FAIL は先に流して確かめた語、$IDLE と $LIMIT は秒
start=$SECONDS; last=$SECONDS; size=0
while :; do
  now=$(wc -c <"$LOG")
  [ "$now" -ne "$size" ] && { size=$now; last=$SECONDS; }
  grep -q "$DONE" "$LOG" && { echo done;  break; }
  grep -q "$FAIL" "$LOG" && { echo fail;  break; }
  [ $((SECONDS - last))  -ge "$IDLE"  ] && { echo idle;  break; }
  [ $((SECONDS - start)) -ge "$LIMIT" ] && { echo limit; break; }
  sleep 5
done
# どの語で抜けても成否は決めない。この後に、その形の完了の事実を照会する
```

抜けた理由（`done` / `fail` / `idle` / `limit`）を完了報告へ残す。どの軸で待ちが終わったかが
分かると、次に配布する人が上限と間隔を決められる。

## 待ちの上限と照会の間隔

**上限を決めずに待たない。** 着手の時点で上限を決め、完了報告へ書く。

**既定の秒数は置かない。** 形によって桁が変わる（レジストリへの公開は分、ストアの審査は日）。
既定を置くと、桁の合わない形へも同じ値が使われる。

**照会のループの待機は必須で、既定は 5 秒とする。** 3 軸の見張りを採らない場合も同じで、
`sleep` を持たない照会のループを書かない。配布先の API は利用の上限を持ち、間を置かない照会は
その上限へ達して、待ちの途中で照会そのものが失敗する。

**間隔にだけ既定を置けるのは、上限と違って形で桁が変わらないためである。** 照会 1 回の費用は
形によらずほぼ同じで、長い待ちでは伸ばしてよい。縮めるときは、その配布先の利用の上限を
確かめてから決める。

## 上限に達したとき

**成功にも失敗にも倒さない。未確定として止め、完了の事実の照会へ移る。**

| 照会の結果 | 扱い |
| --- | --- |
| 完了の事実が新しくなっている | 完了として扱う。照会した対象と値を完了報告へ残す |
| 完了の事実が変わっていない | 未確定のまま止め、運用者へ渡す。上限・照会した対象・返ってきた値を残す |
| 照会そのものが失敗する | 未確定のまま止める。**照会できないことを完了と読み替えない** |

**未確定のまま `release-verification` へ進めない。** 出ていない版を確かめることになる。
