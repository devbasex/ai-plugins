# 配布の形: モバイルアプリ（iOS・Android）


ストアの審査を経て公開されるもの。**公開が即時に完了しない**点が他と違う。

- **起点**: 直前の版のタグ
- **検証への配布**: 内部テスト・クローズドテストの配布先へ出す。審査が軽いか不要な経路が
  用意されていることが多い。ここまでが工程の続きとして進めてよい範囲である
- **公開**: ストアへ提出する。**提出は公開ではない。** 審査を通って初めて利用者へ届く。
  審査で落ちることがあり、その場合は直して出し直す
- **取得**: 利用者が更新する。自動更新の設定に依るため、古い版が長く残る
- **取り消し**: 段階的公開の途中なら止められる。公開済みの版は新しい版で直す

**この工程は提出までで終わらない。** 完了の判定は「審査を通って公開された」ことに置く。
審査待ちの間は工程が続いている状態で、`release-verification` はまだ始められない。
待ちが長い場合は、待っていることと次に確かめる時期を完了報告へ残す。
